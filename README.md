# CSC 193A - Fancify My Text

Dimitry Visochin

**Live page:** https://xplosivecow.github.io/CSC193A-FancifyMyText/fancifymytext.html

## Files

- `fancifymytext.html` - the page with the Text and Fancify field sets
- `fancifymytext.js` - the JavaScript that styles the text

## What it does

- **Bigger!** makes the text in the text area 24pt.
- **FancyShmancy** makes the text bold, blue and underlined. **BoringBetty** sets it back to normal.
- **Moo** uppercases the text and adds "-Moo" to the last word of each sentence (a sentence ends with a period).
